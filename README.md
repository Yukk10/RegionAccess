# RegionAccess

Дополнение к **WorldGuard**: белый и чёрный списки для регионов и права администрации на таблички и мобов в чужом привате.

- Ядро: **Leaf / Paper 26.3** (Java 25)
- Зависимость: **WorldGuard 7** (+ WorldEdit / FAWE)
- Для телепорта нарушителей нужна команда `/spawn <ник>` (EssentialsX и т. п.), её можно заменить в конфиге.

## Скачать

Готовый `.jar` — во вкладке **Releases** репозитория, либо во вкладке **Actions** → последний запуск → артефакт `RegionAccess`.

Релиз публикуется сам: при пуше в `main` с новой версией в `build.gradle.kts` GitHub Actions создаёт тег `v<версия>` и релиз с `.jar` и `config.yml`. Описание релиза берётся из `.github/release-notes/v<версия>.md`, если такой файл есть.

## Команды

Команды выполняются **находясь на территории своего региона** — применяются к нему.
Если регионов в точке несколько, берётся регион с наибольшим приоритетом, владельцем которого вы являетесь.

| Команда | Что делает |
|---|---|
| `/rg whitelist on` | Включить белый список — находиться в регионе могут только его владельцы и участники |
| `/rg whitelist off` | Выключить белый список |
| `/rg whitelist` | Показать текущее состояние |
| `/rg blacklist add <ник>` | Внести игрока в чёрный список региона |
| `/rg blacklist remove <ник>` | Исключить игрока из чёрного списка |
| `/rg blacklist list` | Список игроков в чёрном списке региона |
| `/rgaccess reload` | Перезагрузить `config.yml` (админ) |

Работают также `/region` и `/regions`. Все остальные подкоманды `/rg` обрабатывает WorldGuard как обычно.

## Как это работает

- Посторонний в регионе с включённым белым списком (или игрок из чёрного списка) каждые **5 секунд** получает предупреждение на экране.
- Владельцы и участники региона под белый список не попадают и уведомлений не получают.
- Если после **10** предупреждений игрок не ушёл — от имени консоли выполняется `spawn <ник>`.
- Если игрок покинул регион, счётчик обнуляется.
- Интервал, количество, вид предупреждений (заголовок / actionbar / чат) и команда наказания настраиваются в `config.yml`.

## Права

| Право | По умолчанию | Описание |
|---|---|---|
| `regionaccess.use` | все | `/rg whitelist`, `/rg blacklist` в своём регионе |
| `regionaccess.bypass` | op | Белые и чёрные списки на игрока не действуют |
| `regionaccess.manage.others` | op | Управлять списками любого региона, а не только своего |
| `regionaccess.signs` | op | Ставить, ломать и редактировать таблички в чужом привате (миры — `signs.worlds` в конфиге) |
| `regionaccess.entity` | op | Бить и ломать сущности в чужом привате: мобов, рамки, картины, стойки, вагонетки, лодки. На игроков не действует (миры — `entities.worlds` в конфиге) |
| `regionaccess.reload` | op | `/rgaccess reload` |
| `regionaccess.admin` | op | Все права выше |

Действия с правами `regionaccess.signs` и `regionaccess.entity` разрешаются ещё до проверки WorldGuard, поэтому его сообщение «Hey! Sorry, but you can't…» не появляется.

## Конфигурация

Все тексты, которые видят игроки, находятся в `plugins/RegionAccess/config.yml` в разделе `messages`, у каждого блока — комментарий, где он используется. Формат — [MiniMessage](https://docs.advntr.dev/minimessage/format.html). Пустая строка `""` отключает сообщение.

Данные регионов хранятся в `plugins/RegionAccess/data.yml`.

## Сборка

```
./gradlew build
```

Jar появится в `build/libs/`.
